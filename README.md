# Habĭtus — Gestión personalizada de hábitos

Habĭtus es un servicio que convierte tus objetivos en hábitos mediante un sistema personalizado basado en tu situación actual.

## Contenido del proyecto

- `index.html` — Página principal con onboarding, pago demo y flujo completo.
- `contact.html` — Página de contacto con EmailJS integrado.
- `script.js` — Lógica del onboarding, envío de datos y pantallas dinámicas.
- `styles.css` — Estilos del sitio.
- `email-template.html` — Plantilla opcional para EmailJS.

## Tecnologías

- HTML5  
- CSS3  
- JavaScript  
- EmailJS

## Instalación

Solo abre `index.html` en tu navegador.  
No requiere servidor.
